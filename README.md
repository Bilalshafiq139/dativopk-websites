# DATIVOPK website portfolio

Live demo websites built by DATIVOPK. Each folder is one static site (HTML/CSS/JS, no build step) served by GitHub Pages.

| Site | Folder |
|---|---|
| Nexora Academy | `academy/` |
| Gridline: Excel & Data Analytics | `excel-course/` |
| Mehr Dental Studio | `dentist/` |
| Ember & Oak Steakhouse | `restaurant/` |
| Dastaan Studio (wedding) | `wedding-photographer/` |
| Zoya Malik Studio | `photographer/` |
| Hamza Qureshi, Data Analyst | `data-analyst/` |

On GitHub Pages the small Node APIs in each `api/` folder do not run, so forms and admin panels work in demo mode (saved in the browser only). Each site's own README explains running it with Docker.

Business names, people, phone numbers and sample records are placeholders. Photos are free-licence Unsplash images or original renders.
